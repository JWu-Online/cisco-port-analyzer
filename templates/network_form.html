Observium's database

The map reads what Observium already knows (its devices and their CDP/LLDP links) straight from its MySQL database. It only reads; nothing in Observium changes.

The password is used for this one read and never saved. The other fields are remembered. With the website filled in, each switch on the map links to its Observium page.

    Setting up database access (one time, on the Observium server)

    Observium's database usually only accepts connections from the Observium server itself. Someone with root on that server does this once. Use this PC's IP address where it says 10.1.2.3; if this PC's address changes, use its subnet instead, like '10.1.2.%'.

    1. Make a user that can only read the three tables the map needs, only from this PC: 
      sudo mysql
CREATE USER 'portanalyzer'@'10.1.2.3' IDENTIFIED BY 'a long password';
GRANT SELECT ON observium.devices    TO 'portanalyzer'@'10.1.2.3';
GRANT SELECT ON observium.ports      TO 'portanalyzer'@'10.1.2.3';
GRANT SELECT ON observium.neighbours TO 'portanalyzer'@'10.1.2.3';
    2. Let MySQL accept connections from the network: in its config (often /etc/mysql/mariadb.conf.d/50-server.cnf or /etc/mysql/mysql.conf.d/mysqld.cnf), change bind-address = 127.0.0.1 to the server's own IP, then sudo systemctl restart mysql (or mariadb).
    3. Only let this PC reach port 3306. With ufw: sudo ufw allow from 10.1.2.3 to any port 3306 proto tcp.
    4. Back here: fill in the server, the user and password, and click Test connection.
    How each switch's layer is decided
    Core
    Models that are usually core (Nexus 7000/9500, Catalyst 6500/6800/9600), firewalls and routers. With none of those, the switch linked to the most others.
    Distribution
    Models that are usually distribution (Catalyst 4500, 9400, 9500, Nexus 5000/3000), or a switch one step below the core with other switches below it.
    Access
    Models that are usually access (Catalyst 2960, 3560-3850, 9200, 9300, Dell PowerConnect, Aruba S3500), and everything at the edge.
    Your choice
    Click a switch on a map and pick its layer. It's saved, and every map uses it from then on.
    Links
    The CDP and LLDP neighbours Observium found. Neighbours it doesn't monitor are drawn dashed if they're routers or switches; phones, access points and servers are left out.
    Buildings
    From the switch list on the Port Analyzer page, matched by address. Anything not on it shows Observium's location.
