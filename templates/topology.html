How this page decides Active, Inactive and Unsure

A port is Active if any of these happened in the last {{ '%g'|format(data.months) }} months:

  1. Its link is up right now.
  2. show interfaces link says the link went down since then (a port that has been down since the switch started doesn't count).
  3. show interfaces shows a recent Last input or Last output.
  4. An earlier run of this page saw it up.

Otherwise it's Inactive, but only if the switch can see back {{ '%g'|format(data.months) }} months: its uptime, plus earlier runs. A member that restarted recently has forgotten its history, so its idle ports are Unsure until enough time passes or earlier runs cover the gap.
